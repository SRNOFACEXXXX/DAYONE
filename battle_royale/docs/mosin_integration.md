# Mosin-Nagant integration

The public weapon ID is `&"mosin"`; ammunition ID is `&"762x54r"`.
`WeaponDB.get_def(&"mosin")` returns its `WeaponDef`. For loot, call
`WeaponDB.create_state(&"mosin", mag, reserve)` to get a `WeaponState` and hand
that same instance to the pickup/inventory flow. Both counts survive drops.
`WeaponDB.add_ammo(state, &"762x54r", rounds)` fills reserve up to 25 and returns
the amount accepted. For a new full weapon, omit mag and reserve. The magazine
holds five rounds.

The local player holds right mouse button to aim. Press F while aiming to swap
between iron sights and ACOG when `BRMatch.has_acog_for(soldier)` returns true.
Expose `func has_acog_for(soldier: Soldier) -> bool` on the match; the controller
asks it for the currently equipped weapon and reverts to iron sights as soon as
it returns false.
If the method is absent or returns false, ACOG cannot be selected. F outside
aiming keeps weapon inspect. AK-47 and M4 use the same iron/ACOG ADS controls
with a generic screen-space optic indicator. Both sights
use the same hitscan shot and the weapon fires once per trigger press, with a
1.45 second bolt cycle. The bolt moves in the first-person model after each shot.
Reload currently uses the existing whole-magazine reload system (3.2 seconds),
so individual round loading would require a separate change to `soldier.gd`.

The original low-poly asset is `blender/mosin_source.blend`, generated by
`blender/build_mosin.py`. The exported GLB and Godot wrappers are in
`game/assets/models/weapons/`. Materials are embedded; no remote asset is used.
